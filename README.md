## Core Patterns

- **Wide To Close Cinematic**: Cinematic Scaffolding: sequence diagnostics from wide shot (cluster/host) -> medium shot (service) -> close-up (failing line).
- **Practical Application**: Root-cause crash investigations and memory leak diagnoses.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
